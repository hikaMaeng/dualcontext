**분야: 컴퓨터 하드웨어 / GPU / 컴퓨터 사양** (폴더 이름은 `gpu-hardware` 와 필요하면 `pc-hardware`)

* 대상: GPU · 그래픽 카드 · CPU · 메인보드 · 메모리 · 저장장치 · 노트북/PC 사양, 벤치마크, 호환성, 소비전력, 가격과 세대 비교 같은 자료.
* 검색어 예: `gpu`, `graphics card`, `gpu specs`, `cpu benchmark`, `computer hardware`, `pc build`, `laptop specifications`, `hardware qa`, `nvidia`, `benchmark`, `chip`.
* 표 형태(제품별 사양 행) 데이터이면 사양 열들을 `body` 템플릿에 「열이름: 값」 목록으로 풀어 써서 검색과 분석에 쓸 수 있게 해라.
* 프로시저 예시 방향(그대로 쓰지 말고 데이터에 맞게): 사양 비교 / 용도별 적합성 판단(게임·AI 학습·편집) / 병목·호환성 점검 / 성능 대비 비용·전력 효율 분석.
* 분야를 하나 또는 둘 만든다. 하나만 만들 경우 `gpu-hardware`.
