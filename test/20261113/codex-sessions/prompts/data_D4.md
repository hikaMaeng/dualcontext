**분야: 정보보안 / 클라우드 / 네트워크 / IT 인프라** (폴더 이름은 `it-security` 와 필요하면 `cloud-network`)

* 대상: 취약점(CVE) 설명, 보안 사고 · 위협 분석, 보안 용어, 클라우드 서비스 · 아키텍처 문서, 네트워크 프로토콜 지식, 서버 · 가상화 · 컨테이너 운영 지식 같은 자료.
* 검색어 예: `cve`, `vulnerability descriptions`, `cybersecurity`, `threat intelligence`, `mitre attack`, `cloud computing`, `networking qa`, `kubernetes`, `sysadmin`, `security qa`.
* CVE 류는 식별자(CVE-xxxx), 심각도 점수, 영향 제품, 설명이 있으면 `body` 에 모두 담아 라우팅과 분석에 쓰일 수 있게 해라.
* 프로시저 예시 방향(그대로 쓰지 말고 데이터에 맞게): 취약점 심각도 · 영향 범위 평가 / 공격 경로와 완화책 정리 / 클라우드·인프라 설계 선택 비교(비용 · 가용성 · 보안) / 사고 타임라인 · 원인 재구성.
* 분야를 하나 또는 둘 만든다. 하나만 만들 경우 `it-security`.
