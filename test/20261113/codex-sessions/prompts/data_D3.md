**분야: 소프트웨어 개발 / 프로그래밍** (폴더 이름은 `software-dev` 와 필요하면 `devops-qa`)

* 대상: 프로그래밍 질문과 답변(StackOverflow 류), 오류 메시지와 해결, API · 라이브러리 문서, 코드 설명, 개발 도구 · DevOps 지식, 소프트웨어 공학 문서 같은 자료.
* 검색어 예: `stackoverflow`, `programming questions`, `code qa`, `error messages`, `python documentation`, `software engineering`, `devops`, `github issues`, `api documentation`.
* 질문과 답변이 한 쌍인 데이터이면 `title` 은 질문 요약, `body` 는 질문과 채택/상위 답변을 함께 담는다.
* 프로시저 예시 방향(그대로 쓰지 말고 데이터에 맞게): 오류 원인 진단(증상 → 원인 후보 → 확인 방법) / 해결안 비교(트레이드오프 · 호환성) / 코드 · 설정 검토 체크(재현 조건 · 버전 의존) / 베스트 프랙티스 정리(근거 · 예외).
* 분야를 하나 또는 둘 만든다. 하나만 만들 경우 `software-dev`.
