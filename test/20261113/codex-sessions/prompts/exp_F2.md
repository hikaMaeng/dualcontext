**주제 F2: 한 IT 조사원의 같은 자료에 프로시저가 둘 이상 필요한 질의 — 질의 4개**

* 질의마다 **하나의 조사원 코퍼스**를 대상으로 하되, **서로 다른 분석 관점 둘 이상**이 한 번에 필요해야 한다. 4개 질의는 **서로 다른 4개 코퍼스**(GPU 사양 · CVE · AI 논문 · 소프트웨어 개발 Q&A · IT 기업 뉴스 중 4개)를 쓴다.
  * GPU 예: 두 제품의 사양 비교 + 전원/장착 조건 점검 + 전력 대비 사양
  * CVE 예: 심각도 평가 + 공격 조건/방어 지점 + 영향 제품·수정 범위
  * AI 논문 예: 주장·근거 추출 + 벤치마크 해석 + 기법 비교
  * 개발 Q&A 예: 오류 원인 진단 + 해결 대안 비교 + 경계 사례
* `expect_procedures` 에는 그 조사원에 연결된 프로시저 이름들(둘 이상)을 `researchers_and_procedures.txt` 에서 골라 적는다(라우터는 조사원당 프로시저 상위 2개).
* gold_facts 는 한 코퍼스 안의 **여러 행**(서로 다른 행 최소 3개)에서 모아야 하고, 단순 조회가 아니라 **비교 · 집계 · 조건 판단**이 필요하도록 설계한다(예: 「두 GPU 중 PSU 요구가 더 큰 쪽과 그 차이」, 「세 CVE 중 REJECTED 가 아닌 것의 점수 순위」).
* 프로시저가 실제로 답변 구조를 바꾸는지(표 · 비교 형식 · 부족 항목 표시 등)도 report.md 에 관찰로 적는다.
