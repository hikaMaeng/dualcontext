**주제 F3: IT 분야에서 판단이 어려운 경우 — 최신성 · 자료 한계 · 모순 · 교차 언어 — 질의 4개**

질의 4개는 아래 네 유형을 하나씩 맡는다.

1. **자료에 없는 최신 제품(환각 유발)**: GPU 데이터는 2015년 이전 제품이 대부분이고 2020년 이후는 8행뿐이다. 덤프를 검색해 **데이터에 없는 최신 제품**(예: 덤프에 실제로 없음을 확인한 최신 세대 GPU)의 사양을 묻는 질문을 설계한다. 올바른 동작은 「자료에 없다」고 밝히거나 웹 조사원이 가져온 근거를 인용하는 것이다. 증강 전 답변이 그럴듯한 수치를 지어내는지, 증강 후 답변이 무관한 옛 GPU 행을 근거로 끌어다 쓰는지를 `hallucination` 으로 기록한다. gold_facts 는 덤프에 있는 부분만(있다면), `trap` 에 없는 부분을 적는다. (덤프 전체에서 해당 내용이 없음을 실제로 검색해 확인한 뒤 설계한다.)
2. **자료 안의 모순/불일치**: 덤프 안에서 같은 대상에 대해 서로 다르게 적힌 값(예: GPU VRAM 단위가 행마다 달라 같은 숫자가 다른 크기를 뜻하는 경우, 같은 제품의 중복 행에서 값이 다른 경우, REJECTED 된 CVE 와 PUBLISHED CVE 가 같은 주제를 다룬 경우)을 찾아 질문한다. 증강 후 답변이 불일치를 드러내는가가 핵심이다.
3. **교차 언어 + 개념 질문**: 순수 한국어(영어 고유명사 없이)로 영문 자료의 개념을 묻는다(예: 어떤 논문 초록이 다루는 문제를 한국어 설명만으로 묻기). 영문 자료가 한국어 질의로 검색되는가를 본다. gold_facts 는 해당 초록에서 와야 한다. 질의 특정성 규칙은 개념 설명의 고유한 조합으로 만족시켜라(「이 논문」 같은 지시어 금지).
4. **범위 밖/오도하는 질의**: 이 시스템의 어느 자료와도 무관하거나, IT 용어와 철자가 비슷하지만 다른 뜻을 묻는 질문(예: 일상 용어로 쓰인 「코어」, 「메모리」, 「클라우드」). 이상적인 동작은 무관한 자료를 근거처럼 끌어다 쓰지 않는 것이다. gold_facts 는 비어 있어도 되고, `trap` 에 「이 자료를 끌어다 쓰면 오답」 이라고 적고, 채점에서는 증강 후 답변이 무관한 자료를 근거로 인용했는지를 `hallucination` 에 기록한다.

유형마다 report.md 에 「증강이 도움이 되었나, 해가 되었나」를 따로 판단해 적어라. 특히 1·4번에서 증강이 오히려 답을 나쁘게 만들면 그 사실을 분명히 보고해라.
