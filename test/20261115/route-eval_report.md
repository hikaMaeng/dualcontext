# 라우팅 단계 구성 실측 보고 (조사원 선택)

- 평가 세트: `route-eval-set.json` 136개 = calibration 74(규칙 조정에 쓴 질의 포함) + real 32(실제 로그 질의, 규칙 조정에 쓴 적 있음) + **heldout 30(조정에 쓰지 않음)**. 정답은 작성자(Claude)가 직접 단 라벨이다.
- 실행: `route-eval-run.mjs` → `POST /router/preview`(요청마다 설정을 실어 보내 저장 설정은 불변), 채점 `route-eval-score.mjs`, 원본 수치 `route-eval-summary.json`, 질의별 결과 `route-eval-results/`.
- 지표 정의는 `route-eval-score.mjs` 머리말. topicRecall(tR)=주제 충족률, fullRecall(fR), extra=불필요 선택 평균, negClean/negEmpty=무관 질의 비율, avg=평균 선택 수, p50(ms).

## 설정
A 기본(임베딩 top3·0.67·마진0.05, 규칙 분해) / W 임베딩 넓게(top6·0.6, 분해 없음) / B 임베딩 넓게→LLM(없음 허용) / C B+규칙 분해 / D LLM만(후보 27개 전부) / E B에서 LLM이 「없음」 불가 / F LLM 분해+임베딩 / G LLM 분해+임베딩→LLM.

## 해석
1. **임베딩은 후보 추출로는 충분하다.** W(넓은 후보)의 재현율이 세 세트에서 0.99~1.0이다. 문제는 선택·거절이다: W의 extra 3.6~4.6, 무관 질의 negClean 0.
2. **임베딩 → LLM(B)이 최선의 균형.** A 대비 heldout 재현율 0.955→1, extra 0.27→0, 무관 질의 negClean 0.5→0.875, real 재현율 0.901→0.979, extra 0.56→0.03. 같은 설정을 두 번 돌렸을 때 질의별 선택이 같았던 비율 126/136(`route-eval-summary.json` agreement) — LLM 단계는 비결정적이나 지표는 거의 같았다.
3. **LLM만(D)은 B보다 나을 것이 없다**: 재현율은 같거나 약간 낮고(calibration 0.984), 무관 질의 거절이 약하며(heldout negClean 0.75), 더 느리다(p50 5.5~7.2초, 후보 27개 전부를 프롬프트에 넣음).
4. **「없음」 허용이 거절 능력의 핵심(E)**: 허용하지 않으면 negClean 0.25(heldout), 0(calibration).
5. **규칙 분해(C)는 이득이 없다**: real extra 0.03→0.38로 오히려 늘고 재현율 이득은 0.979→0.99(질의 1개 수준). **LLM 분해(F·G)는 비용만 크다**: F는 A와 동일 지표에 지연만 증가, G는 p50 15.7초(heldout)~32초(real)에 이득 없음.
6. 반증된 가설: 「LLM 분해가 복합 질의 재현율을 끌어올린다」 — 아니다(F real 0.917 ≈ A 0.901, G ≈ C ≈ B 범위).

## 한계 (결론의 강도)
- 라벨은 작성자 판단이며 heldout은 30개뿐이다. 차이 0.955 vs 1(질의 1건)은 통계적으로 약하다; extra·negClean 차이가 더 일관적이다.
- real 32개는 규칙 조정에 쓴 적이 있어 A·C에 유리하게 편향될 수 있다 — 그럼에도 B가 앞선다.
- 지연은 서버 한 대를 다른 작업과 나눠 쓴 환경이다(동시성 3). B p95 27~48초, 일부 95초대(B r2 real)는 추론 모델의 변동이며 절대값이 아니다. 질의당 p50 약 3~6초가 LLM 단계 비용이다.
- 답변 품질(최종 컨텍스트) 비교는 하지 않았다. 「선택이 정답과 같은가」만 측정했다.
- 부정 집합 일부는 경계 사례(예: 「초등 분수 가르치기」 vs 육아)를 포함한다.

## 결정
기본 설정을 B 하이브리드(분해 없음, 임베딩 top6·0.6 → LLM, 「없음」 허용)로 변경했다(`defaultRouterConfig`). **이미 저장된 설정은 바꾸지 않았다**; 관리자 화면에서 단계를 추가하거나 설정을 직접 바꿔 적용한다. 지연(p50 약 4초 추가)이 허용되지 않으면 A(임베딩 한 단계)가 남는다.
