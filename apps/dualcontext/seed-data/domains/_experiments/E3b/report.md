# E3b 복합 질의 실험 결과

4개 질의를 사전 등록하고 순차 실행했다. HTTP 응답은 4/4건 받았으나 E3b-3의 증강 전 답변은 서버 내부 시간 초과로 생성되지 않았다. 각 행의 수치는 `scores.json` 기준이다. 적중률은 정확한 `hit`만 분자로 삼고 `partial`, `miss`, `contradict`는 적중으로 세지 않는다. 무효 항목은 분모에서 제외한다. 소요 시간은 POST의 실제 경과 시간이다.

| 유형 | 사실 적중률 전 → 후 | 근거 포함률 | 조사원 라우팅: 기대 일치 / 누락 / 추가 | 프로시저: 기대 일치 / 누락 / 추가 | 소요 시간 |
|---|---|---|---|---|---|
| E3b-1 수치·방향 차이 | 0/3 → 0/3 | 0/3 | 1 / 0 / 2 | 2 / 0 / 1 | 239,177ms |
| E3b-2 부분 답변 | 0/2 → 2/2 | 2/2 | 1 / 0 / 2 | 2 / 0 / 1 | 240,961ms |
| E3b-3 최신 정보 혼합 | 전 채점 불가 → 0/2 | 0/2 | 1 / 1 / 2 | 2 / 0 / 1 | 301,268ms |
| E3b-4 범위 밖 | 해당 없음 → 해당 없음 | 해당 없음 | 1 / 0 / 2 | 1 / 0 / 3 | 175,822ms |

프로시저 일치 수는 모든 조사원의 선택을 합친 집합 기준이다. 해당 프로시저가 적절한 조사원과 짝지어졌다는 뜻은 아니다. 특히 E3b-1·2·3의 `근거 신뢰도 점검`은 금융 조사원이 아니라 각각 웹 또는 판례 조사원에만 붙었다. 네 질의 모두 조사원·프로시저 집합이 기대와 정확히 같지는 않았다. 기대 목록은 실험자가 정한 기준이며 추가 조사원이 항상 유해하다는 의미는 아니다.

같은 사실에 대해 양쪽 답변이 모두 있는 비교 가능 항목은 **0/5(0%) → 2/5(40%)**다. 전체 유효 항목의 증강 후 적중은 2/7(28.6%), 근거 포함은 2/7(28.6%)이다. 증강 전은 답변이 존재한 5개만 평가했으므로 0/5와 2/7을 직접 비교하면 안 된다.

## 유형별 판정

1. **수치·방향 차이 — 도움이 제한적이고 일부 해로움.** 기대 금융 행 두 개가 검색되지 않아 72.9% 감소와 70.3% 증가를 보여주지 못했다. 증강 전은 근거 없는 45~55%, 구인 898만 건을 제시했다. 증강 후는 전달된 컨텍스트에 해당 수치가 없다고 밝힌 점은 신중했으나, 금융 자료 전체에 없다고 단정해 실제 덤프와 충돌했다. 또 다른 시점일 수 있는 웹·합성 고용 수치를 정반대 모순으로 취급했다. 두 금리 확률의 연도·관측 시점이 동일하다고 증명되지 않아 이 사례는 **동시점의 확정적 모순 검증으로는 약하다**.
2. **부분 답변 — 도움이 됨.** ETF 380억 달러와 314억 달러를 검색하고 정확히 답했으며, 부산 거주 투자자 순매수액은 컨텍스트에 없다고 밝혔다. 코스피는 질문이 특정 시점을 지정하지 않았으므로 2,454포인트가 아닌 다른 행의 2,857포인트도 가능한 답이다. 이 때문에 F3은 무효 처리했다. 부산 표현 두 가지의 덤프 전체 문자열 검색 결과는 0건이지만 다른 표현의 간접 기록까지 없다는 증명은 아니다.
3. **최신 정보 혼합 — 비교 불가, 목표 미달.** 금융 조사원은 선택됐지만 필요한 구인·코스피 근거 행은 들어오지 않았고, 웹 조사원도 빠져 관련 웹 결과가 없었다. 증강 후는 최신 금리를 확인할 수 없다고 밝히고 합성 자료의 과거 금리를 따로 제시했다. 증강 전은 시간 초과이므로 증강의 개선·악화 비교는 할 수 없다. F3은 F1과 같은 사건의 구인 건수 사실을 중복해 독립 사실로 보기 어려워 무효다.
4. **범위 밖 — 답변 실용성에 해로움.** 웹은 사진 합치기 관련 결과 5개를 반환했고 무관한 산업·의학 자료도 들어왔다. 증강 후는 무관한 자료를 사진 편집의 근거로 인용하지 않았지만, 컨텍스트에 상세 단계가 없다며 사용자가 요청한 절차를 제공하지 않았다. 증강 전은 GIMP를 이용한 캔버스 생성·배치·PNG 내보내기 순서를 제시했다. 실제 GIMP 화면에서 절차를 실행 검증하지는 않았지만, 제공된 답변의 구체성은 증강 후에 감소했다.

## 관찰과 가설

- 유효 사실 7개 중 실제 근거가 전달된 2개는 모두 적중했고, 전달되지 않은 5개는 모두 적중하지 못했다. 이 작은 표본에서는 조사원 선택 이후 **행 검색의 재현율**이 중요한 병목일 가능성이 있다. 인과관계를 입증하는 통제 실험은 아니다.
- 각 기대 프로시저 이름은 전체 집합에 있었지만, 위에서 보듯 판단 대상인 금융 자료에 신뢰도 점검이 붙지는 않았다. 집합 단위 일치만 보면 실제 절차 적용 대상을 과대평가할 수 있다.
- E3b-4는 관련 웹 결과가 있어도 요약 스니펫에 상세 조작법이 없으면 답변이 과도하게 제한될 가능성을 보여준다. 작가 지시, 모델 행동, 검색 결과 품질 중 원인은 분리하지 못했다.

## 한계

표본은 네 질의뿐이고 합성 뉴스·금융 자료는 실제 사실의 근거가 아니다. 모델이 설계와 채점을 모두 맡아 판정 편향이 가능하며 독립 평가자가 없다. E3b-2 F3과 E3b-3 F3은 실행 후 발견된 설계 결함으로 원본을 유지하고 분모에서 제외했다. E3b-1 역시 동일 시점의 명백한 모순이라고 검증할 수 없다. E3b-3의 웹 최신 사실과 E3b-4의 편집기 실제 동작은 별도로 검증하지 않았다. HTTP 성공은 모든 내부 답변 생성 성공과 다르며 E3b-3의 증강 전 답변은 실패했다.
