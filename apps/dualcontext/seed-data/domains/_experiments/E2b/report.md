# E2b 복합 질의 실험 보고서

## 설계와 결과

사전 고정 질의 4개, HTTP 응답 4개. 증강 전 답변 생성 성공 1개, 증강 후 3개; Q4는 양쪽 모두 내부 시간 초과다. HTTP 성공과 답변 성공은 다르며 내부 오류는 요청 재시도 조건인 HTTP 5xx 또는 클라이언트 타임아웃에 해당하지 않았다. 합성 산업·금융 자료는 실제 사실이 아니다.

각 사실은 완전 일치만 hit로 계산하고 partial은 적중에 포함하지 않았다. 답변 생성 실패는 unavailable로 기록하고 분모에서 제외했다. 근거 포함률은 pairs[].materials에서 사전 인용의 출현을 확인했다. 시간은 요청 시작부터 응답 저장까지의 경과 시간이며 전후 생성 시간의 합이 아니다.

| 질의 | 증강 전 | 증강 후 | 근거 포함률 | 라우팅 | 경과 |
|---|---:|---:|---:|---|---:|
| Q1 (무효) | 평가 불가 | 0/3 (0.0%) | 0/3 (0.0%) | 조사원 1/1, 프로시저 1/2, 추가 조사원 2 | 304.8초 |
| Q2 (무효) | 0/3 (0.0%) | 1/3 (33.3%) | 1/3 (33.3%) | 조사원 1/1, 프로시저 1/2, 추가 조사원 2 | 300.3초 |
| Q3 | 평가 불가 | 3/3 (100.0%) | 3/3 (100.0%) | 조사원 1/1, 프로시저 1/2, 추가 조사원 2 | 302.1초 |
| Q4 | 평가 불가 | 평가 불가 | 3/3 (100.0%) | 조사원 1/1, 프로시저 2/2, 추가 조사원 2 | 302.1초 |

전체 원시 사실 적중률은 증강 전 0/3 (0.0%), 증강 후 4/9 (44.4%)다. 각각 다른 분모이며 전후 효과 비교값이 아니다. 무효 설계를 제외한 유효 사실은 증강 전 평가 불가, 증강 후 3/3 (100.0%)다. 양쪽 답변이 모두 생성된 유효 질의는 0개라 유효한 전후 적중률 비교는 불가능하다.

Q1의 모든 사실은 질문에 보고서 시점이 지정되지 않았고, Q2의 모든 사실은 범주별 기사 하나로 유일하게 특정되지 않아 무효로 표시했다. 해당 항목은 삭제하지 않았고 원시 수치에만 포함했다. Q3와 Q4는 각 세 행을 특정할 단서가 있다.

## 관찰

- Q3은 지정된 사전 행 3개가 모두 자료에 들어왔고, 증강 후 세 사실이 모두 맞았다. 정의·요건·수치 표와 현행성 한계를 제시했다. 다만 증강 전 답변은 없어 개선 폭을 측정할 수 없다. 검색 발췌문에 법령 시행일이 없는데 현행법과 일치한다고 단정한 부분은 근거가 부족하다.
- Q2는 합성임을 분명히 밝히고 공정 소재 사례의 3개월 예측을 전달했다. 증강 전은 제공된 자료 없이 매출·납기 등 구체적인 수치를 검증된 사실처럼 제시했다. 증강 후는 원문의 운영비 상승 전망을 확정형으로 서술했다. 사례 지정이 모호하므로 특정 행 미회수를 성능 결함으로 단정하지 않는다.
- Q1은 검색된 다른 시기 자료를 표로 정리하고 지수 방향이 없음을 밝혔으나, 사전 지정 3개 행은 회수되지 않았다. 다른 고용 시기의 지표를 비교한 것이어서 동시점 추세나 모순으로 단정하기 어렵다.
- Q4는 지정된 의학 자료와 기대 프로시저 둘을 모두 가져왔으나 양쪽 답변이 시간 초과여서 최종 답변의 사실성과 형식은 평가할 수 없다.

## 라우팅과 프로시저

4개 모두 기대 조사원은 선택됐으나 조사원별로 예상 밖 조사원 2개씩도 선택됐다. 기대 프로시저는 대상 조사원 기준 Q1 1/2, Q2 1/2, Q3 1/2, Q4 2/2다. 각 선택과 과잉 목록은 scores.json에 기록했다. Q3는 정의와 수치 추출이 선택되고 신뢰도 점검은 웹 조사원에 선택됐다. Q1·Q2·Q3 답변에 표와 부족 항목이 나타나지만, 동일 자료에서 프로시저를 바꾼 대조군이 없고 사용자 질문에도 비교·부족 확인이 명시돼 있어 프로시저가 형식 변화를 일으켰다고 단정할 수 없다. 활성 라이터는 기본 조립 템플릿이다.

## 약점 가설과 한계

- 상위 3개 조사원을 항상 선택하는 설정이 단일 코퍼스 과제에도 관련성이 낮은 판례나 웹 자료를 유입시킬 가능성이 있다. 이 표본의 관찰이며 원인 검증은 하지 않았다.
- 상위 3행 검색은 특정 단서가 약한 질의에서 의도된 행 대신 유사한 다른 시점·사례를 택할 수 있다. Q1·Q2는 질문 설계의 모호함이 혼재하므로 검색기 단독 결함의 증거는 아니다.
- 답변 생성 시간 초과가 전후 비교 자체를 막았다. 각 단계 제한이나 원인은 서버 내부를 조사하지 않아 알 수 없다.
- 4개 질의와 12개 사실의 작은 표본이며 그중 6개 사실이 설계상 무효다. 채점자는 모델이고 독립 검증자가 없다. 미지원 주장은 제공된 자료 기준의 미확인 주장이지 외부 현실에서 반드시 거짓이라는 뜻은 아니다. 실제 법령, 의학적 진료 적합성 및 외부 사실 검증은 수행하지 않았다. 프로시저의 인과 효과, 반복 실행 안정성, 독립 채점 신뢰도도 미검증이다.
