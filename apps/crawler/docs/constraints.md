# 제약

| 항목 | 규칙 |
| --- | --- |
| 상태 | 없음. 볼륨을 붙이지 않는다(크롤 캐시는 dualcontext DB). Crawl4AI 의 내부 Redis 는 컨테이너 수명과 같다. |
| 자원 | 헤드리스 Chromium 이 있어 `shm_size: 1gb` 가 필요하고(기본 64MB 면 탭이 죽는다), `mem_limit: 3g`. 동시 요청이 늘면 메모리를 더 쓴다. dualcontext 는 요청을 직렬로 보낸다. |
| 네트워크 | 호스트 포트는 `127.0.0.1` 만. 토큰은 비밀이 아니라 「토큰이 있어야 컨테이너 밖 바인딩」 조건을 채우는 값이다. 프로젝트 네트워크 안의 다른 컨테이너(특히 인증 없는 dualcontext 관리자)와 같은 네트워크라는 점이 SSRF 의 남는 위험이다 — `apps/dualcontext/docs/constraints.md` 의 「크롤러 조사원」. |
| 버전 | 이미지 태그를 고정한다(`0.9.5`). API 본문 모양이 바뀔 수 있어 올릴 때는 `apps/dualcontext/src/server/collect/crawler/client` 의 변환과 시험을 다시 본다. |
| 비루트 | `appuser`. |
| 신뢰 | 이 컨테이너는 임의의 공개 웹 페이지를 브라우저로 연다. 렌더링 결과(마크다운)는 신뢰할 수 없는 입력이며 프롬프트 주입 문구를 담을 수 있다(라이터 프롬프트에 그대로 들어간다). |
